# Design Tokens

- Colors — `tokens/colors.ts` (12 keys per theme: dark + light)
- Typography — `tokens/typography.ts` (Inter, sizes, weights, line heights)
- Spacing — `tokens/spacing.ts` (11-step scale: 0–24)
- Radius — `tokens/radius.ts` (sm, md, lg, xl, full)
- Shadows — `tokens/shadows.ts` (sm, md, lg per theme)
- Blur — `tokens/blur.ts` (glass 12px, subtle, heavy)
- Motion — `tokens/motion.ts` (fast 150ms, base 300ms, slow 400ms, functional only)
